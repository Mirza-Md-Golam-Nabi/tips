## Version Check ([⬆️](#installation))

Node version check:

```sh
node -v
```

npm version check:

```sh
npm -v
```

yarn version check:

```sh
yarn -v
```

## Yarn Install ([⬆️](#installation))

If you want to install yarn in your local machine, run this command in your terminal:

```sh
npm i -g yarn
```

## Uninstalled create-react-app Package ([⬆️](#installation))

Remove the globally installed create-react-app package from your system.

```sh
npm uninstall -g create-react-app
```

Or

```sh
yarn global remove create-react-app
```

## Install Vite ([⬆️](#installation))

Install vite latest version

```sh
npm create vite@latest
```

**N.B.** This command will prompt you with a few questions. You can safely answer **yes** to all of them.

## Install React project ([⬆️](#installation))

Installed a fresh React project using this command:

```sh
npx create-react-app my-app
```

Or

```sh
yarn create react-app my-app
```
